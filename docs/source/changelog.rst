Changelog
=========

Version 0.1.0 (2026)
--------------------

Initial release of FESOMP.

Features
~~~~~~~~

* Mesh loading from NetCDF and ASCII formats
* Lazy computation of topology, geometry, and spatial indices
* Spatial queries: nearest neighbor, radius search, bounding box
* 2D map plotting with Cartopy integration
* Multiple map projections (Robinson, PlateCarree, Polar, Mercator)
* Vertical transect visualization
* Interpolation to regular grids (nearest, IDW, linear)
* Reusable interpolator classes for efficiency
* Sea ice diagnostics (area, volume, extent)
* Vertical diagnostics (Hovmoller, heat content, volume mean)
* Mixed layer depth calculations
* Meridional overturning circulation (MOC, AMOC)
* Basin and region masking utilities
